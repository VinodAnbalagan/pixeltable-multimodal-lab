# Pixeltable Multimodal Lab

Multimodal AI experiments built on [Pixeltable](https://docs.pixeltable.com), using open models, run locally and on Pixeltable Cloud (beta).

## Projects

1. **Hallucination Spotter** — a vision-language model captions each video frame; an object detector checks whether the objects it mentions are really there. Hallucinated words get flagged.
2. **Silent Film Foley** — a silent video gets matching sound effects, retrieved by audio-text similarity (CLAP).
